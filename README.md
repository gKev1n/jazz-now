# JAZZ, NOW.

用黑胶唱机和磁带展示 8 种当下的爵士风格的可操作网页应用：每种风格有自己的配色、
Web Audio 实时合成的律动，画面随节拍响应。React + TypeScript + Motion，无后端、无外部音频文件。

- 视觉参考：[x.com/niramayo2096/status/2107591861561127238](https://x.com/niramayo2096/status/2107591861561127238)（95 秒动态图形视频）。视觉按参考还原；参考本身是自动播放的视频，交互、音频与律动动效为本项目新设计；文案为中文。
- 想让 AI 从零复现，见 [PROMPT.md](PROMPT.md)。
- 声音为浏览器实时合成的演示音色，不是录音。

## 启动

```bash
npm install
npm run dev      # http://localhost:5178
npm run build    # 产物在 dist/
```

## 操作

| 场景 | 操作 |
| --- | --- |
| 封面 | 点风格标签 / 左下唱片 / 右下磁带 进入对应曲目；`→` 或 `空格` 从第 1 首开始 |
| 曲目 | 点唱机或磁带 = 播放/暂停（唱片惯性起停、唱臂抬落、指示灯、频谱、节拍点）；`空格`/`K` 同效 |
|  | `←` `→`、屏幕边缘箭头、触屏左右滑动 切换；`1`–`8` 直达；顶部进度条分段可点；`JAZZ, NOW.` 回封面 |
|  | 播放中每首约 10.5 秒后自动进入下一首（与参考节奏一致）；暂停则停留 |
|  | `M` 或顶部 SOUND 按钮 静音 / 取消静音（记住偏好）；静音时画面律动照常 |
| 结尾 | 点任一风格 = 记为“你的选择”（本地保存）并跳转播放；底部文字回封面；`Home`/`End` 跳封面/结尾 |

## 声音与律动

- 声音为 Web Audio 实时合成（演示用，非录音）。每种风格按自身拍号 / BPM / 调性写了 4 小节循环：7/8 点弦琶音与 3 对 7 复节奏、齐奏快跑 + 第 4 小节重拍切分、碎拍、错位律动（swing + 军鼓拖后）、四踩、12/8 铃型、加花 fill 等。
- 黑胶在唱臂落下后出声（含针落声与底噪），磁带在落位后出声（含按键声与嘶声）；暂停/切换时淡出。
- 画面律动全部由“已到达扬声器的音符事件”驱动（音频时钟前瞻调度，rAF 按 `currentTime - outputLatency` 取出）：底鼓→背景泛光与唱机/磁带轻微下沉；每拍→节拍点与指示灯；每小节→分隔线上的播放头（7/8、12/8 的小节长度可见）；各乐器→对应「主要音色」标签点亮；频谱条为真实 FFT。
- 切到后台标签页时声音随画面一起暂停。

## 结构

- `src/tokens.ts` — 所有动效时长 / 缓动（逐帧测自参考）
- `src/audio/` — 合成音色（synth.ts）、8 种律动（patterns.ts）、前瞻调度器与分析器（index.ts）
- `src/engine.ts` — 单一 rAF 循环：转速惯性、消费音频事件、频谱、进度、自动换曲；直接写 DOM，不触发 React 重渲染
- `src/App.tsx` — 离散状态机（scene / playing / favorite）、键盘、滑动、焦点交接
- `src/components/*` — 唱机、磁带、频谱、场景
